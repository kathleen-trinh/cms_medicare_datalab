# cms_medicare_datalab
Collection of SQL Files and Notebooks for CMS Medicare Claims

## Description
The purpose of this repository is to store publicly available data from 
the Centers of Medicare and Medicaid Services (CMS) in a database 
for and along with analytics and data science use cases.

This repository contains:
- SQL to create and set up a database for CMS data storage
- Python notebooks for exploratory data analysis (EDA) and data science projects using CMS data
